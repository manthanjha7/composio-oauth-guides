# Recorded setup attempts

The live agent can't log in to developer consoles, so "attempting the setup" happens here:
the **agent does the configuration work** and a **human does only the logins**, and every
round is recorded. A guide claim becomes 🧪 **Tested** only when it is backed by an entry here.
